# Airline Data Analysis

## 📌 Overview

This project analyzes airline booking and operational data to identify low occupancy flights, study revenue patterns, and uncover opportunities to improve airline profitability. Using SQL, Python, and data visualization, the analysis focuses on occupancy optimization and revenue growth.

---

## 📊 Dataset

* Source: Airline relational database (`travel.sqlite`)
* Contains airline operational and booking data from multiple interconnected tables.

### Tables Used:
- aircrafts_data  
- airports_data  
- boarding_passes  
- bookings  
- flights  
- seats  
- ticket_flights  
- tickets  

---

## 🛠️ Tools & Technologies

* Python  
* SQL (SQLite)  
* Pandas  
* Matplotlib  
* Seaborn  
* Jupyter Notebook  

---

## 🔍 Key Analysis Performed

* Data cleaning and preprocessing  
* Database exploration using SQL queries  
* Aircraft seat capacity analysis  
* Ticket booking and revenue trend analysis  
* Fare condition analysis  
* Aircraft occupancy rate calculation  
* Revenue impact analysis with 10% occupancy increase  

---

## 📈 Key Insights

* Some aircraft operate with low occupancy rates  
* Business class generates higher average revenue  
* Revenue is strongly linked with booking volume  
* Underutilized flights reduce profitability  
* Even a 10% increase in occupancy can significantly improve annual turnover  

---

## 🎯 Business Impact

* Helps identify low performing flights  
* Supports occupancy optimization strategies  
* Improves revenue decision making  
* Enables pricing and route optimization  
* Supports airline profitability growth
